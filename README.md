## How to Use

1. **Open the Portfolio**
   - Simply open `index.html` in your web browser
   - No server setup required!

2. **Customize Your Portfolio**
   - Edit `index.html` to update personal information
   - Modify colors in `styles.css` by changing CSS variables
   - Adjust animations in `script.js` as needed

3. **Deploy Your Portfolio**
   - Upload to any web hosting service
   - GitHub Pages (free hosting)
   - Netlify (free hosting with automatic deployments)
   - Vercel (free hosting)

## Customization Guide

### Change Color Scheme
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #667eea;      /* Main color */
    --secondary-color: #764ba2;    /* Secondary color */
    --accent-color: #f093fb;       /* Accent color */
    --dark-bg: #0f172a;            /* Dark background */
    --light-bg: #f8fafc;           /* Light background */
}
```

### Update Personal Information
- Change your name, title, and description in the hero section
- Update contact details (phone, email, location)
- Add your social media links

### Add More Projects
- Duplicate the featured-project section
- Update project details and technologies used
- Add project images

### Update Skills
- Add or remove skills in the skills section
- Adjust skill levels (width percentages)
- Add new skill categories
